# 🏥 Règles concernant les comas

Si vous êtes dans le comas, il faut attendre les secours. S’il n’y a personne au bout des 5 minutes vous pouvez respawn à l'hôpital mais ça vous coûtera $2000 (attention ne spammez pas la touche sinon vous allez payer plusieurs fois).

Si vous êtes dans le coma, vous ne pouvez pas parler, vous êtes inconscient…

Toute personne tombée dans le coma (peu importe le métier peu importe l'accident) devra être automatiquement emmenée à l'hôpital par les EMS.&#x20;

Si un EMS vous réanime, vous pourrez vous souvenir partiellement de ce qu'il vous est arrivé. Si vous respawnez à l'hôpital, vous devez tout oublier de ce qui a provoqué votre perte de conaissance.

(Cependant, si vous avez été mis dans le coma pour X raison qui n'implique pas d'autre

joueurs, vous pourrez vous souvenir de la raison de votre coma.)

Lorsqu'un EMS intervient dans une scène RP et que vous nécessitez un soin particulier, vous devez absolument respecter leurs décisions.

On ne déplace pas une personne dans le coma, on appelle les EMS ou le LSPD.
